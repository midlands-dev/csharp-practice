\# csharp-practice



My practice projects from getting back into C# and .NET. I last wrote C# properly in 2017, so a lot of this was new to me.



Each folder is a small console app for one topic:



\- \*\*AsyncPractice\*\*: async/await. Two slow tasks took 4 seconds one after the other and 2 seconds side by side.

\- \*\*LinqPractice\*\*: filtering, sorting, grouping and summing a list of products.

\- \*\*NullablePractice\*\*: nullable types and handling nulls.

\- \*\*RecordsPractice\*\*: records, and how they differ from normal classes.

\- \*\*PatternPractice\*\*: switch expressions and pattern matching.

\- \*\*DiPractice\*\*: dependency injection, and the difference between Transient, Scoped and Singleton.

\- \*\*ConfigPractice\*\*: reading settings from appsettings.json, with DI and async.



To run one, open a terminal in the folder and type `dotnet run`. You need the .NET 10 SDK.
